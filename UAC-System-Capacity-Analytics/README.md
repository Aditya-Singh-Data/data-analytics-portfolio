# System Capacity & Care Load Analytics for Unaccompanied Children

**Internship Project — Unified Mentor Pvt. Ltd.**

A data analytics project analyzing the **U.S. HHS Unaccompanied Children Program** from **2023–2025**.

## 🛠️ Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Power BI

## 📊 Project Overview

- Data cleaning and validation using Python
- Exploratory Data Analysis (EDA)
- Monthly trend analysis
- System capacity and care-load analysis
- Power BI dashboard development
- Business insights and recommendations

### Dataset

- Raw data: **1,170 rows × 6 columns**
- Cleaned data: **720 rows × 6 columns**
- **450 empty rows removed**
- Analysis period: **January 2023 – December 2025**
